# 2.0.1 — Actual popup, readable percentage and storage isolation

## User-facing fixes

- Real toolbar popup registered through `action.default_popup`.
- 500px compact dashboard available without first opening ChatGPT.
- Three quota cards restored to one row.
- Range selector narrowed so Usage Trend title and subtitle remain on one line.
- Diagnostics gains horizontal padding and compact Copy / Export / Rebuild actions.
- Toolbar percentage uses Chrome's high-contrast badge plus a larger dynamic icon.
- Cached data remains visible when authentication or storage connection is temporarily unavailable.

## Architecture repair

- One background engine now owns history requests and persistent mutations.
- Popup/page views communicate through an allowlisted runtime protocol.
- Storage APIs are resolved per operation with callback/Promise compatibility.
- Work is checkpointed in bounded slices and resumed by alarms after popup closure.
- Legacy page-worker leases block concurrent migration scans.
- Multiple account indexes require explicit selection; account mismatch cannot overwrite another index.

## Preserved

Stable public key/ID, schema 3, account-scoped storage, staged 24h → 7d → 30d acquisition, archived history, Projects, deduplication, coverage reuse, pacing/cooldowns, reset assumptions, bilingual/theme settings, backup/import, CSV and raw metadata.

## Validation boundary

The current 45-check suite uses simulated extension APIs/backend responses and actual Chromium popup rendering. Native extension install, real authenticated ChatGPT requests and Orion/iPad are not certified by that suite.
